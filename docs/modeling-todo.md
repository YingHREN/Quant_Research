## P0 — 持久化预测产物缓存（PERF-002）

设计文档：`docs/superpowers/specs/2026-07-26-persistent-forecast-artifact-cache-design.md`

目标：全市场预测特征和风险上下文只计算一次并保存到独立硬盘缓存表。只要行情内容和算法版本没有变化，服务重启后搜索 INTC、NBIS 等股票直接读取缓存，不再承担约 50～60 秒的全市场重算。

### 本轮实现

- [x] 建立独立 `data/analysis_cache.db`，不得把缓存表写入原始行情库 `data/prices.db`。
- [x] 建立 `forecast_artifacts` 表，保存全市场特征表、风险上下文、评估结果、行情覆盖元数据和内容指纹。
- [x] 缓存键包含行情内容签名、Ridge 模型版本、特征版本、风险上下文版本和持久化格式版本。
- [x] 缓存命中后从硬盘恢复 DataFrame，并重新构造、验证 `RidgeForecastProvider`；不序列化运行时 provider。
- [x] 使用事务 UPSERT、payload checksum 和完整构建后发布。
- [x] 缓存损坏、SQLite 锁定、磁盘只读、未知格式或反序列化失败时安全退回冷构建，不向网页暴露内部异常。
- [x] 默认最多保留最近两个 artifact；过期版本自动清理，缓存文件可安全删除并重建。
- [x] 自定义测试 provider/evaluator 默认不落盘，显式注入 store 时才参与持久化测试。
- [x] 提供 `ForecastService.prewarm(histories)` 和 `build_forecast_cache.py`，预热最近两个活跃观察日 cohort。
- [x] 覆盖首次写入、全新进程命中、行情新增、同形状历史修订、模型/特征/风险版本、损坏恢复、写入失败、容量和并发回归测试。
- [x] 2026-07-26 完整本地库实测：首次生成 97,080 行特征和 19,061 行风险上下文耗时 62.187 秒，缓存约 12 MB；全新进程 INTC 首次请求 2.231 秒，同进程热请求 0.958 秒。

### 后续持续优化

- [x] 行情更新成功后自动预热已拆分为 `PERF-003` 独立任务；预热失败不能回滚已经成功写入的行情。
- [x] 在网页显示缓存状态：命中、重建中、上次生成时间、对应行情日期和算法版本，避免用户把后台重建误认为网页卡死。
- [x] 增加 `manage_analysis_cache.py` 缓存维护命令：`status` 查看预测/入场信号条目与磁盘占用，`verify` 校验全部 payload checksum，`prune` 默认只预览并要求显式 `--apply` 才按保留数量清理，`prewarm` 复用现有预测预热流程。2026-07-26 对真实缓存只读验收：2 个预测 artifact、11 个入场信号 artifact、13/13 checksum 有效、数据库及 WAL/SHM 共约 71.9 MiB，默认保留策略无需删除。

- [ ] 若单一压缩 payload 读取仍偏慢，再评估把特征表、风险上下文和评估结果拆为独立 artifact，按需读取。
- [ ] 若 SQLite BLOB 超过可接受规模，再比较 Parquet/Arrow 文件加 SQLite manifest；迁移前必须以真实读取时间和磁盘占用为依据。

## P1 — CAN SLIM 四维严格候选池（CANSLIM-001）

目标：用“基本面、技术面、机构面、大盘环境”四个独立门控决定股票能否进入正式候选池。四项必须全部通过；任何一项不通过或数据缺失，都不得进入正式候选池。Ridge、VCP、动量和反转模型只对通过门控的股票排序或解释，不能绕过门控。

### 基本面门控

- [ ] 建立带财报发布日期、修订版本和 `available_at` 的点时季度/年度基本面数据层。
- [ ] 要求最新季度 EPS 同比增长至少 25%，并展示原值、同比基数和报告日期。
- [ ] 计算最近两个季度 EPS 同比增速，识别加速、持平和减速；连续显著减速应明确标记风险。
- [ ] 要求最近季度营收同比增长至少 20%。
- [ ] 检查年度 EPS 是否连续增长，默认至少覆盖最近 3 个完整财年，并单独处理亏损转盈利和异常低基数。
- [ ] 不再把基本面缺失当作中性分；正式候选池中“缺失”等同未通过，另设不影响正式结果的“数据待补”观察池。

### 技术面门控

- [x] 建立基于同一观察日研究股票池的横截面 RS 百分位；采用 63/126/189/252 交易日收益的 40/20/20/20 组合，不再把相对 SPY 的 Sigmoid 近似值冒充横截面排名。
- [x] 在股票池提供 RS 排序、`RS ≥ 80` 和 `RS ≥ 90` 筛选；截至 2026-07-24 的真实快照覆盖 1,016 只合格股票，评分范围 1～99。
- [ ] 要求收盘价位于 SMA50 上方。
