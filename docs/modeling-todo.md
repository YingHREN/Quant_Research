## P1 — CAN SLIM 四维严格候选池（CANSLIM-001）

目标：用“基本面、技术面、机构面、大盘环境”四个独立门控决定股票能否进入正式候选池。四项必须全部通过；任何一项不通过或数据缺失，都不得进入正式候选池。Ridge、VCP、动量和反转模型只对通过门控的股票排序或解释，不能绕过门控。

### 基本面门控

- [ ] 建立带财报发布日期、修订版本和 `available_at` 的点时季度/年度基本面数据层。
- [ ] 要求最新季度 EPS 同比增长至少 25%，并展示原值、同比基数和报告日期。
- [ ] 计算最近两个季度 EPS 同比增速，识别加速、持平和减速；连续显著减速应明确标记风险。
- [ ] 要求最近季度营收同比增长至少 20%。
- [ ] 检查年度 EPS 是否连续增长，默认至少覆盖最近 3 个完整财年，并单独处理亏损转盈利和异常低基数。
- [ ] 不再把基本面缺失当作中性分；正式候选池中“缺失”等同未通过，另设不影响正式结果的“数据待补”观察池。

### 技术面门控

- [ ] 建立基于同一观察日可交易股票池的横截面 RS 百分位，替代当前相对 SPY 超额收益的 Sigmoid 近似值。
- [ ] 默认要求 RS Rating 不低于 80，并提供可配置的 90 分高质量门槛。
- [ ] 要求收盘价位于 SMA50 上方。
- [ ] 要求 EMA10 位于 EMA20 上方，并显示两条均线斜率和最近交叉日期。
- [ ] 要求距过去 252 个交易日最高价不超过 20%，优选不超过 15%；历史不足 252 日时不得冒充完整 52 周指标。
- [ ] 将严格 VCP、紧密平台、枢轴距离和突破量价作为通过技术门控后的排序/准备度证据，不替代基础趋势门槛。

### 机构面门控

- [ ] 建立 13F 点时数据层，保存报告期、提交日、修订日、机构、持仓股数、市值和组合权重。
- [ ] 统计最近若干报告期持有该股票的基金数量及其增减趋势。
- [ ] 识别 Fidelity、Capital Group、Janus Henderson 等配置化长线机构的新增和增持，但不把品牌名单本身当作充分条件。
- [ ] 区分新增、增持、减持、清仓及被动指数持仓，避免把总持仓市值随股价上涨误判为主动买入。
- [ ] 在免费 13F 数据尚未覆盖时，将机构面标记为“数据缺失”，不得继续用当日成交量比率冒充机构持仓。

### 大盘环境门控

- [ ] 建立明确的大盘状态机：修正、反弹尝试、Follow-through Day、Confirmed Uptrend、Uptrend Under Pressure 和 Market in Correction。
- [ ] 使用 SPY、QQQ 及必要时主要指数的价格、成交量、均线和市场宽度交叉确认状态。
- [ ] 定义并统计有效 distribution days，包含窗口、过期、指数上涨消除和聚集风险规则。
- [ ] 只有 Confirmed Uptrend 才允许进入正式候选池；其他状态保留观察结果但禁止标记为可执行候选。
- [ ] 独立显示大盘状态的触发日期、派发日数量、证据和失效条件，不把市场分数伪装成概率。

### 门控、界面与验证

- [ ] 为四维分别输出 `pass`、`fail`、`missing`，以及实际值、阈值、数据日期和简明原因。

## P1 — 高位派发与顶部向下转折风险模型（TOPRISK-001）

目标：建立独立的点时状态模型，区分“普通下跌”与“上涨后处于高位、供应增加并可能形成顶部”的风险。模型不能宣称已经确认真实机构交易，只能输出基于日线、板块和大盘数据的“疑似派发”证据；只有高位背景、供应证据和结构破坏形成递进确认时，才允许影响最终预测决策。

### 高位背景门控

- [x] 第一版用 60 日涨幅、距 252 日高点、SMA50 位置和相对 EMA20 的 ATR 延伸度定义高位背景，并保留最近 10 日因果背景记忆；不因绝对股价高而判定高位。
- [ ] 要求此前存在可复现的有效上涨阶段；处于长期下降趋势或刚从低位反弹的股票不得直接进入顶部风险状态。
- [ ] 将现有 `overheat_score` 拆成可审计原子证据，分别展示短期加速、均线延伸、连续上涨和波动扩张，不直接把综合过热分等同于顶部。
