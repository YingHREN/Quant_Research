# 尾部方向误报审计设计

## 背景与目标

`asymmetric_tail_risk_v1` 在 240 只股票、448,594 个点时样本和 384,686
个外层预测上未通过晋级门槛。校准下跌分不低于 0.40、随后五日终点却上涨
至少 10% 的反例共有 9,405 个。反例中的下跌分与极端反弹分相关系数为
0.81；最高下跌分五分位的实现波动率中位数约为 140%，随后五日平均收益
为 +31.1%。这说明现有两个分类头主要共同识别“两侧高波动”，尚未可靠
识别尾部发生后的方向。

本轮只建立可复现的离线反例审计，回答以下问题：

1. 高下跌分的真实下跌与极端上涨，在观察日可见信息上有何稳定差异；
2. 差异是否跨外层折、半导体、软件、其他板块及主要市场阶段存在；
3. 现有数据能否支持下一轮“两阶段尾部—条件方向”挑战模型。

本轮不修改线上 Ridge、最终决策策略、风险否决权或 UI。

## 方案比较与选择

1. **点时匹配审计（采用）**：在高下跌分样本中，将极端上涨反例与真实
   终点下跌样本按外层折、板块、市场阶段和相近观察月份匹配，再比较观察日
   已知特征。它能隔离时间与环境差异，输出可审计效应量，调参自由度最低。
2. 直接在全部样本训练更复杂的分类器：可能提高训练指标，但会跳过误报
   成因验证，并增加针对已知反例调参的风险。
3. 只看总体分箱或特征相关系数：实现简单，但混合了年份、板块和市场阶段，
   不能证明差异在样本外折中稳定存在。

审计结果只产生下一轮预注册特征假设；不会用同一批反例选择阈值并宣称
样本外有效。

## 样本与互斥标签

沿用 `asymmetric_tail_risk_v1` 的精确执行口径：观察日为 `t`，入场为
`t+1` 开盘，第五个未来交易日收盘为终点，未来五日最低价用于路径最大不利
波动。只审计校准下跌概率不低于 0.40 且所有未来标签已成熟的外层预测。

样本标签固定为：

- `terminal_down`：终点收益不高于 -5%；
- `extreme_up`：终点收益不低于 +10%；
- `path_only_stress`：路径最大不利波动不高于 -7%，但终点位于
  (-5%, +10%)；
- `other`：其余成熟样本。

四类互斥，判定优先级依次为 `terminal_down`、`extreme_up`、
`path_only_stress`、`other`。主要匹配比较只使用 `terminal_down`
与 `extreme_up`；`path_only_stress` 单独报告，不再冒充终点向下方向。

## 点时特征与缺失边界

审计只使用观察日收盘时已经可见的字段：

- 当前 Ridge v4 的 23 个原子特征；
- 当日开盘相对前收盘的跳空幅度；
- `ATR20 / close`、63 日实现波动率及其短期变化；
- 20 日成交额中位数、当日成交额相对 20 日中位数；
- 收盘位置、上影线、带符号成交压力、派发日和突破失败；
- 点时板块、市场阶段和观察月份。

价格和成交额仅作为流动性/尺度代理，不宣称为真实市值。没有可靠的点时
市值时必须输出 `market_cap_unavailable`。当前财报临近字段在 9,405 个
反例中 100% 缺失，因此本轮只报告 `earnings_proximity_unavailable`，
不得填零、推测财报日或加入模型。

## 匹配与统计

每个 `extreme_up` 样本只匹配一个尚未使用的 `terminal_down` 样本。
匹配必须同外层折、同板块、同市场阶段，观察日期相差不超过 63 个自然日；
在可行候选中依次最小化日期距离、实现波动率距离和证券代码，保证完全确定。
无法匹配的样本保留在覆盖报告中，但不进入配对效应量。

对每个连续特征报告：

- 两类原始样本数、缺失率、中位数和四分位距；
- 配对中位差和标准化均值差；
- 按观察日期做固定随机种子的区块 bootstrap 95% 区间；
- 五个外层折中差异方向一致的折数；
- 半导体、软件、其他板块及各市场阶段的同方向性。

对布尔特征报告两类发生率、配对发生率差和同样的折/分组稳定性。报告
Benjamini–Hochberg 校正值，但不得以显著性单独决定是否进入下一轮。

## 下一轮模型假设门槛

某特征只有同时满足以下条件，才可写入下一轮模型的预注册候选集：

- 至少 1,000 对总体匹配样本，且两类该特征可用率均不低于 90%；
- 绝对标准化差异不低于 0.20；
- bootstrap 95% 区间不跨 0；
- 至少四个外层折方向一致；
- 半导体、软件、其他三组中至少两组方向一致；
- 不是未来收益、未来最低价或由目标直接派生的字段。

若没有特征通过，结论必须为“现有日线特征不足以区分尾部方向”，下一步优先
补点时财报日历、真实市值/流通盘或更细粒度成交数据，而不是放松门槛。

若有特征通过，下一轮另行实现两阶段模型：

1. 第一阶段估计未来五日是否发生终点尾部或路径压力；
2. 第二阶段只在已成熟的终点尾部训练样本中估计
   `P(terminal_down | terminal_tail)`；
3. 路径压力保持独立输出，不得代替终点方向；
4. 所有校准、特征筛选和阈值仍只在外层训练集内部完成。

## 输出与失败状态

生成独立的严格 JSON、配对明细 CSV、特征汇总 CSV 和中文 Markdown 报告。
输出包含输入内容指纹、源码提交、工作区状态、样本定义、匹配约束、匹配覆盖、
缺失原因、折/板块/市场阶段结果和预注册候选特征。

以下情况必须失败关闭：键重复、未来标签不成熟、外层折缺失、匹配键不一致、
特征出现非有限值、匹配覆盖不足、财报或市值字段被擅自填充、报告包含绝对
本地路径或凭据形态内容。失败不生成任何线上产物。

## 测试与验收

单元测试覆盖互斥标签优先级、精确点时字段、未来追加不变性、一对一匹配、
63 日边界、无重复使用、确定性、缺失率、效应量、区块 bootstrap、BH 校正、
特征晋级门槛、严格 JSON 与密钥扫描。

真实运行前后执行全量测试。最终报告必须明确回答：当前误报主要由何种
点时条件驱动、哪些差异跨折和分组稳定、哪些字段不可用，以及是否足以进入
下一轮两阶段模型。无论结果如何，本轮 `online_authority=none`。
