# 市场板块收益口径设计

## 目标

消除板块热力图与下钻明细之间的收益口径歧义，并为每只成分股显示最新交易日涨跌幅。

## 指标定义

- 板块区间涨跌幅：板块代理组合在当前所选 5、20 或 60 个交易日内的绝对收益。
- 相对 QQQ 超额涨跌：板块区间涨跌幅减去同期 QQQ 区间涨跌幅。
- 最新交易日涨跌幅：个股最新收盘价相对前一交易日收盘价的变化。
- 20 日相对板块超额涨跌：个股 20 日涨跌幅减去所属板块代理组合 20 日涨跌幅。

所有指标均使用本地数据库截至观察日期的日线数据，不表示盘中实时行情。

## UI 设计

板块热力图同时显示所选周期的板块绝对涨跌幅、相对 QQQ 超额涨跌和向下转折风险。下钻摘要明确标注当前数值是所选周期板块涨跌幅。

成分股表新增“最新交易日涨跌幅”列，并将“20 日相对强弱”改名为“20 日相对板块超额涨跌”。表格上方提供简短公式说明。

## 数据流

后端市场上下文在每只成分股记录中增加 `daily_return`，由该股票观察日期及前一交易日收盘价计算。板块绝对收益继续使用已有 `returns` 字段；相对 QQQ 收益继续使用已有 `relative_return` 字段。前端只格式化并展示接口字段，不重复计算。

## 验证

- 单元测试验证 `daily_return` 的计算使用观察日期之前最近两个有效收盘价。
- 静态资源测试验证中英文标签、公式说明和前端字段绑定存在。
- 运行市场上下文、市场页面资源以及 API 相关测试，确认没有回归。
