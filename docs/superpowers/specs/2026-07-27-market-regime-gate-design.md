# CAN SLIM 大盘环境门槛 v1 设计

## 目标

用观察日收盘前可见的 SPY、QQQ、成交量和本地市场宽度，输出可复现的
`pass / fail / missing` 大盘门槛。只有 `confirmed_uptrend` 才通过；其他状态
不得把股票标记成正式上涨候选。该门槛保留 Ridge 原始输出，不冒充收益概率。

## 状态

- `confirmed_uptrend`：确认上涨，门槛 `pass`。
- `uptrend_under_pressure`：上涨承压，门槛 `fail`。
- `market_in_correction`：市场调整，门槛 `fail`。
- `rally_attempt`：调整后的反弹尝试，尚未确认，门槛 `fail`。
- `range_bound`：无明确趋势共识，门槛 `fail`。
- `unavailable`：基准、历史或宽度不足，门槛 `missing`。

## 因果证据

1. QQQ 与 SPY 的 EMA20、SMA50、SMA200 和 5/20 日收益。
2. 派发日代理：当日跌幅不高于 -0.2%，且成交量高于前一交易日。
3. 派发日记忆：最多保留 25 个交易日；指数较事件收盘上涨至少 5% 时提前移除。
4. 市场宽度：同日可用股票中收盘高于 EMA20/SMA50 的比例；覆盖不足 20 只时门槛缺失。
5. 调整：基准趋势破坏、显著回撤或急跌。
6. 反弹尝试：调整低点后首次上涨日开始，记录尝试日数和低点；创新低则重置。
7. 跟进日代理：反弹第 4～10 日，QQQ 或 SPY 上涨至少 1.5%，成交量高于前日，并站上 EMA20。
8. 承压：确认上涨后派发日聚集、跌破 EMA20 或宽度显著恶化；严重趋势破坏转入调整。

## 合约

每个日期输出状态、门槛、版本、观察日、状态起始日、最近跟进日、反弹日数、
QQQ/SPY 派发日数量、宽度、原始实际值、阈值、原因码和 `point_in_time=true`。
缺失数据不能通过。

## 集成

- `/api/universe` 顶层增加 `market_gate`，每行仅增加轻量 `market_gate_state`。
- 个股 API 顶层增加 `market_gate`，历史预测日期的模型输出包含相同时点的大盘门槛。
- 市场页、股票池页和个股标题显示大盘状态、门槛及简明原因。
- `forecast_decision_policy` 原始方向不被覆盖；大盘门槛只禁止“正式上涨候选”语义。

## 验收

- 追加未来数据不改变历史状态。
- 派发日按 25 日过期并可由 5% 上涨提前移除。
- 创新低重置反弹尝试。
- 第 4 日以前不得确认跟进日。
- 缺少 SPY/QQQ、少于 200 个共同交易日或宽度覆盖不足时返回 `missing`。
- 真实股票池冷构建仍不超过 5 秒，完整测试通过。
