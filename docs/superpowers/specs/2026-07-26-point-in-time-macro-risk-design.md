# 点时宏观环境风险设计

## 目标

建立独立、可审计的宏观风险层，用于解释利率、通胀/能源、信用和避险环境是否共同增加股票与板块的短期回撤风险。第一版不修改 Ridge 数值、不取得最终策略否决权，也不把规则分数解释为概率。

## 数据与点时约束

宏观数据保存于独立的 `data/macro_data.db`，不写入原始股票价格库。每条记录必须包含：

- `series_id`
- `observation_date`
- `available_at`
- `value`
- `realtime_start`
- `realtime_end`
- `source`

历史重放只允许读取 `available_at <= 观察时点` 的记录。同一序列和观察日期存在多个版本时，只选择当时已经发布的最新版本；未来修订不得改写旧日期结果。

第一批序列为：

- 利率：`DGS2`、`DGS10`
- 通胀与能源：`CPIAUCSL`、`DCOILWTICO`
- 信用：`BAMLH0A0HYM2`
- 避险：`VIXCLS`、`DTWEXBGS`

`fetch_macro_data.py` 使用 FRED API 的 `output_type=4` 下载初次发布值。FRED 只提供实时日期而非精确发布时间，因此保守地把数据设为该实时日期 UTC 日末可用，避免同日交易前视。完整修订历史仍需后续 ALFRED vintage 导入与校验。

## 第一版规则层

模型键为 `macro_risk_v1`，总权重 100：

- 利率压力 30：两年期收益率高位、快速上升、10Y/2Y 倒挂；
- 通胀与油价 25：CPI 同比偏高、油价短期冲击；
- 信用与流动性 25：高收益债利差高位与快速扩大；
- 市场避险 20：VIX 高位/跳升、美元短期快速走强。

可用证据权重不足 70% 时拒绝给总分。总分状态为低风险、观察、高风险、严重风险。每项证据保留实际值、阈值、方向、权重、序列、观察日期和可用时间。

## 接口与界面

- 市场与板块接口返回独立 `macro_risk`，市场状态原分不受影响。
- 个股历史日期的 `model_outputs.macro_context` 显示当时宏观总分、覆盖率、状态、四组贡献和触发条件。
- 宏观数据库不存在或覆盖不足时显示明确原因，不回退到今日值，不伪造中性分。
- 宏观数据库文件变化会进入市场页缓存键；新增数据后无需修改股票行情 revision。

## 后续晋级

规则层仅提供透明基线。进入最终决策前必须：

1. 补齐至少十年初次发布值和修订版本；
2. 训练未来 5 日、20 日回撤风险模型；
3. 估计半导体、软件及其他板块的宏观敏感度；
4. 使用扩展窗口、禁入期和标签净化进行走步回测；
5. 对比 Ridge、现有风险策略、宏观规则层和无技巧基线；
6. 证明不是通过把多数上涨降级为中性制造表面提升。
