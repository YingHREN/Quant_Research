# 股票池范围筛选设计

## 目标

将左侧股票池中容易产生组合歧义的“主动池”和“仅研究池”复选框，
替换为一个互斥的“股票范围”选择器。用户可以先选择要搜索的股票集合，
再用 VCP、紧密平台、技术门槛、RS、板块以及后续新增条件继续缩小范围。

默认范围为“全部股票”，确保用户能直接在当前全部可操作股票中搜索形态，
而不需要先理解主动池和研究池的内部关系。

## 范围定义

选择器提供四个稳定值：

1. `all`（全部股票）：不按池成员身份排除任何股票。
2. `active`（主动池）：`pool_membership.active` 为真的股票。
3. `research`（研究池）：`pool_membership.research` 为真的股票；
   若一只股票同时属于主动池和研究池，也包含在内。
4. `catalog`（候选库）：属于研究候选目录、尚未加入研究池且不属于主动池的股票。

未提供范围值、值为空或收到未知值时，按 `all` 处理，避免旧状态或异常输入
意外隐藏股票。

## 界面

- 在现有“筛选条件”区域顶部增加“股票范围”下拉选择器。
- 默认显示“全部股票”。
- 移除“主动池”和“仅研究池”两个复选框。
- 中文与英文界面均使用稳定的 i18n 键。
- 选择器沿用现有暗色表单样式，在窄侧栏中占满可用宽度。
- 股票数量继续使用现有“显示数量 / 全部数量”反馈，不增加第二套计数。

## 筛选语义

筛选顺序在实现上保持单条纯函数管线：

1. 股票代码搜索。
2. 股票范围。
3. VCP、紧密平台、接近枢轴点等形态条件。
4. 技术门槛状态。
5. 横截面 RS。
6. 数据新鲜度。
7. 板块分类。

除同一组选项已有的“任选其一”行为外，不同筛选维度之间采用 AND：
例如“全部股票 + 严格 VCP + RS ≥ 80”返回全部股票中同时满足两项条件的股票。
未来新增筛选只需加入同一个 `filters` 对象和 `filterTickers` 管线，
无需为每个股票范围重复实现。

## 状态与兼容性

- 前端状态使用 `filters.poolScope`，初始值为 `all`。
- 旧的 `activePool` 和 `researchOnly` 不再由界面产生，也不参与新筛选。
- 不改变后端 `/api/universe` 数据结构、研究池增删接口或成员定义。
- 切换股票范围只重绘本地股票列表，不重新请求市场数据。
- 当前已选股票若被新范围隐藏，右侧分析面板保持不变；用户选择新的可见股票后再切换。

## 测试

- 默认 `all` 返回输入中的全部股票。
- `active`、`research`、`catalog` 分别遵守上述成员定义。
- 主动池与研究池重叠股票出现在两个对应范围中，但不出现在候选库。
- 未知范围安全回退到全部股票。
- 范围与严格 VCP、紧密平台、门槛、RS 和板块条件可以叠加。
- 模板包含可访问的“股票范围”选择器，不再包含两个旧池复选框。
- 实际仪表盘切换范围后更新列表和显示数量，不触发额外股票详情请求。
- 中文和英文切换时选择器标签与四个选项均正确本地化。
