# 仪表板请求自动恢复设计

日期：2026-07-26  
状态：已确认设计，待实施

## 背景与根因

网页初始化时，`loadUniverse()` 在同一个 `try/catch` 中依次加载股票池和默认单股详情。股票池成功后，页面已经能显示最近共同日期和覆盖范围；如果随后单股详情请求失败，外层异常处理仍会把它当作股票池失败，并把已成功加载的股票池清空为 `0/0`。

截图中顶部仍显示 `2026-07-24` 和 `52/194 当前`，但左侧股票池变为 `0/0`，正是这个错误边界过大的可观察结果。后端检查同时确认 `/api/universe` 和 `/api/stocks/GOOGL` 在诊断时均可返回 `200`，因此不能把该现象解释为股票池本身缺失。

## 目标

1. 股票池成功后，即使默认单股详情失败，也必须保留股票池及其覆盖信息。
2. 对短暂网络失败和服务端 `5xx` 提供有限自动重试。
3. 自动重试耗尽后提供明确、局部的手动恢复入口。
4. 更新或刷新失败时尽量保留上一次成功数据，避免整个页面退回空白状态。
5. 不对客户端输入错误、未知股票等确定性 `4xx` 响应重复请求。

## 非目标

- 不引入无限轮询或后台常驻健康检查。
- 不修改预测、VCP、Pocket Pivot 或风险模型。
- 不改变后端 API 数据结构。
- 不在本轮拆分单股大响应接口；该性能优化继续保留在全局 TODO。

## 方案

### 请求重试

在前端 API 层提供可测试的有限重试能力：

- 默认首次请求失败后最多重试两次。
- 等待时间采用固定的短递增序列，约为 `400ms`、`1200ms`。
- 仅重试网络错误、无法读取的临时响应和 HTTP `5xx`。
- HTTP `4xx` 直接返回结构化错误，不重试。
- 每个用户动作只产生一个重试序列，禁止重叠定时器和无限递归。

### 错误边界

将初始化拆为两个独立阶段：

1. `loadUniverse()` 只负责股票池请求、股票池状态和初始证券选择。
2. 股票池成功提交到 store 后，再单独调用 `selectTicker()`；单股请求失败只更新详情区错误状态。

`selectTicker()` 的异常不得冒泡到股票池加载的异常分支，也不得清空 `universe`、`universePayload` 或覆盖信息。

### 保留成功数据

- 首次股票池加载失败且没有旧数据：显示空态与“重新加载股票池”按钮。
- 已有股票池后刷新失败：继续显示旧股票池，在状态区提示刷新失败并显示重试按钮。
- 单股详情失败：保留股票池和上一次成功详情；若选择的是新股票且没有旧详情，则只清空详情可视内容并显示“重试当前股票”。
- 重试成功后自动清除对应错误和恢复按钮。

### 用户界面

增加两个局部恢复动作：

- 股票池状态区：“重新加载股票池”。
- 单股详情状态区：“重试当前股票”。

按钮仅在对应请求最终失败时显示；请求进行中禁用并显示加载状态，避免重复点击。中文与英文文案同时提供，按钮可通过键盘操作并具有明确的可访问名称。

## 数据流

```text
页面初始化
  -> 请求股票池（最多 3 次实际尝试）
     -> 成功：保存股票池并立即渲染
        -> 独立请求所选股票详情（最多 3 次实际尝试）
           -> 成功：渲染详情
           -> 失败：仅详情区报错，可手动重试
     -> 失败：保留旧股票池；无旧数据时显示空态，可手动重试
```

## 错误处理

- 网络连接失败：可重试。
- HTTP `500` 至 `599`：可重试。
- JSON 解析失败：作为临时无效响应可重试；最终仍失败时显示“响应格式无效”。
- HTTP `400`、`404`、`409` 等：不自动重试，保留后端错误代码用于本地化。
- 新的选择发生时，旧单股请求及其重试结果必须通过现有请求序号机制失效，不能覆盖新选择。

## 测试与验收

### API 层

- 网络失败两次、第三次成功时返回成功结果。
- `500` 后成功时会重试。
- `404` 不重试。
- 三次均失败时保留最后一个结构化错误。

### 仪表板状态

- 股票池成功、默认 GOOGL 详情失败：股票池仍为 `194/194`，覆盖日期不丢失。
- 已有股票池后刷新失败：旧列表仍可见。
- 单股失败后点击“重试当前股票”可恢复详情。
- 股票池失败后点击“重新加载股票池”可恢复列表。
- 快速切换股票时，旧请求的延迟重试不得覆盖新股票。
- 中英文按钮、错误状态和加载状态均正确。

### 浏览器回归

- 使用本地真实服务验证股票池、GOOGL 和 NBIS 正常加载。
- 人工制造一次单股失败，确认股票池不变为 `0/0`。
- 自动恢复和手动恢复均不得改变图表日期范围、锁定日期或模型图层选择。
