# 技术门槛未达项展示设计

## 目标

在个股页顶部的“门槛 X/4”徽章附近，直接说明哪些技术门槛未达到，
让用户无需猜测扣分原因或只依赖鼠标提示。

## 展示规则

- 读取现有 `technical_gate.conditions`，不修改门槛计算模型或 API。
- 至少一个条件为 `fail` 时，在徽章组下方显示“未达”列表。
- 条件为 `missing` 时单独显示为“数据缺失”，不得冒充失败。
- 四项全部通过时隐藏详情区域，保持顶部简洁。
- 每项显示简短名称、当前值和要求；数值按条件使用百分比。
- 中文和英文界面都使用稳定的 i18n 键。
- 详情区域允许换行，不得撑宽顶部面板或挤压报价卡。

## 四项文案

1. 收盘价高于 SMA50。
2. EMA10 高于 EMA20。
3. EMA10 与 EMA20 的 5 日斜率均为正。
4. 距 52 周最高收盘价不超过 20%。

条件载荷中的 `actual` 是相对差值或最低斜率，`threshold` 是判定阈值；
界面将二者格式化为百分比。缺失原因只显示本地化的简短说明，不暴露内部异常。

## 测试

- 3/4 时显示唯一未达项、当前值和阈值。
- 多项失败和缺失时分别归类。
- 4/4 时清空并隐藏详情。
- 切换语言后动态内容重新本地化。
- 页面模板包含稳定、可访问的状态容器。
