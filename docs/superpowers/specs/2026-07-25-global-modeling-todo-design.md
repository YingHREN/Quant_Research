# 全局量化建模 TODO 设计

## 目标

将 `docs/modeling-todo.md` 作为项目唯一的全局量化建模任务表，统一使用中文维护。后续讨论形成的新模型、数据、回测、界面和基础设施事项都追加到该文件，不再建立相互重复的待办清单。

## 结构

文件顶部提供全局任务索引，使用以下字段：

| 字段 | 含义 |
|---|---|
| 编号 | 稳定且可引用的任务编号，例如 `MACRO-001` |
| 优先级 | `P0` 至 `P3` |
| 状态 | 待调研、调研中、待实施、实施中、待验证、已完成或受阻 |
| 任务 | 一句话说明预期结果 |
| 依赖 | 前置数据、模型或接口；没有时使用 `—` |

详细任务继续按主题分组，使用 Markdown 复选框保留现有完成状态。每个新增主题至少说明目标、子任务和验收标准。

## 中文化范围

- 标题、章节、任务描述、状态和维护规则全部改为中文。
- 文件路径、模型键、接口名、代码标识符和行业通用缩写保持原文，例如 `ridge_direction_v1`、`forecast_decision_policy`、VCP、QQQ。
- 现有复选框状态必须原样保留，不因翻译改变已完成或未完成状态。
- 已完成的基础能力保留在“已完成基础”章节，避免重新进入待办队列。

## 首个新增任务

新增 `MACRO-001`：建立点时宏观环境风险模型，将利率、国债、通胀、油价、信用和流动性作为第四类风险来源影响 Ridge。

第一阶段只允许宏观模型提示风险或将 Ridge 的上涨判断降级为中性；只有长期数据上的严格走步回测证明稳定增益后，才允许训练收益校准层或授予下跌否决权。

子任务包括：

1. 扩充至少十年的股票、ETF 和宏观历史数据。
2. 建立带 `available_at` 和历史版本信息的 FRED/ALFRED 点时数据层。
3. 计算利率压力、通胀/油价冲击、信用与流动性压力、市场避险压力。
4. 训练未来 5 日和 20 日回撤风险模型。
5. 估计半导体和软件板块的宏观敏感度。
6. 以第四类风险来源接入 `forecast_decision_policy`。
7. 在界面展示宏观分数、状态、贡献因素及其对 Ridge 的影响。
8. 使用扩展窗口、标签净化和禁入期完成严格点时走步回测。

验收要求：

- 所有输入只在其真实发布日期或之后可用。
- 独立展示 Ridge 原始结果与宏观调整结果。
- 与 Ridge、现有风险策略和无技巧基线比较。
- 不能依靠将大多数上涨判断降为中性来获得表面改善。
- 在多个宏观阶段和半导体、软件分组中均报告概率校准、下跌召回、误报和回撤指标。

## 维护规则

- 新讨论事项先进入全局索引，再补充详细子任务。
- 状态变化时同步更新索引与详细章节。
- 实现完成不等于任务完成；通过验收标准后才能标记为已完成。
- 被否决或无样本外增益的实验保留结论，并从活动队列移入研究记录。
- 每次修改尽量只涉及相关任务，避免无关任务状态漂移。
