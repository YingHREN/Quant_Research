# 图表模型图层筛选器设计

日期：2026-07-26

## 目标

历史图表同时显示多个模型事件时，标签会互相遮挡并覆盖 K 线。本功能允许用户选择图上展示哪些模型信号，在保留历史证据的同时降低视觉噪声。

筛选只影响图表标记，不改变后端计算、API 数据、下方模型输出、因子详情或最终决策。

## 交互设计

在日期范围和预测周期控件下方增加“图表信号”折叠面板。面板默认收起，并显示当前已启用图层数量。

面板提供三个快捷操作：

- 核心信号：恢复推荐的默认组合。
- 全部显示：启用所有模型标记。
- 全部隐藏：隐藏所有模型标记。

用户可以独立勾选以下图层：

1. 严格 VCP 形成
2. VCP 放量突破
3. Pocket Pivot
4. 紧密平台
5. 向上结构反转候选
6. 向上早期反转观察
7. 突破前高
8. 突破下降趋势线
9. 更高低点

默认只启用前三项核心入场信号：严格 VCP 形成、VCP 放量突破、Pocket Pivot。图表已有的均线、枢轴价格线、预测起点和预测方向不属于事件图层，不受本筛选器影响。

## 状态与数据流

筛选状态由前端维护，键使用稳定的模型类型名称，不依赖翻译文本。状态变化时，图表控制器使用现有股票 payload 重新生成 marker 集合，不发送 API 请求，也不重新计算模型。

用户选择写入浏览器 `localStorage`。页面刷新、语言切换和切换股票后继续沿用。存储内容损坏或浏览器禁止本地存储时，安全回退到核心信号默认值。

“全部显示”包含未来前端版本认识的全部图层；“核心信号”始终恢复产品定义的核心集合。

## 可访问性与响应式

- 折叠面板使用原生 `details/summary`。
- 每个图层使用带文本标签的 checkbox。
- 快捷操作使用 button，并提供明确的中文和英文文案。
- 状态摘要通过可见文字展示启用数量。
- 窄屏时复选项自动换行，面板不覆盖图表。

## 代码边界

- `index.html`：筛选器语义结构。
- `i18n.js`：中英文名称、摘要和快捷操作文案。
- `charts.js`：图层定义、默认集合、筛选 marker、重新渲染接口。
- `app.js`：读取/保存选择、绑定控件、同步 UI。
- `dashboard.css`：紧凑折叠布局和移动端样式。

不修改后端信号定义和 API schema。

## 测试与验收

自动化测试覆盖：

- 默认只显示三个核心图层。
- 单独启用或关闭图层会立即改变 marker 集合。
- 全部显示、全部隐藏和核心信号快捷操作正确。
- 无效或旧版存储值会被规范化。
- 切换语言、日期范围和股票不会重置选择。
- 中英文文案和 HTML 控件存在。

浏览器验收使用 NBIS：

- 一年视图默认不再出现密集的结构反转、更高低点和趋势线突破标签。
- 可以只显示 Pocket Pivot，并在 2026-06-09 看到对应标记。
- 切换股票再切回 NBIS 后选择保持。
- 刷新页面后选择保持。
