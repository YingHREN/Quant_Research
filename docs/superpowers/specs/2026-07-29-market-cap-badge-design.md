# 市值标记设计

## 目标

在股票池列表和所选证券摘要中显示易读、可审计的市值标记，帮助用户快速判断公司规模，并为后续市值排序与区间筛选提供稳定的数据契约。

本次只增加显示和底层字段，不增加市值筛选控件或排序选项。

## 数据来源与时间口径

- 使用 `research_prices.db` 的 `universe_memberships.market_cap`，不在页面加载时调用外部 API。
- 市值随成员目录的 `effective_from` 生效，因此必须读取观察日有效的成员记录，不能跨期取最新值。
- API 为每只股票输出：
  - `market_cap`：美元计价的原始数值；
  - `market_cap_asof`：市值记录的生效日期；
  - `market_cap_tier`：由统一分级函数计算的规模等级。
- 当前研究目录约覆盖 1014/1043 只股票。ETF、目录外股票或缺失值返回 `null`，不能用 `0` 代替。
- 非有限值、负值和零值均按不可用处理。

## 分级规则

采用互斥、下界包含的美元市值区间：

| 等级键 | 中文 | 英文 | 区间 |
|---|---|---|---|
| `mega` | 超大盘 | Mega cap | `market_cap >= 200B` |
| `large` | 大盘 | Large cap | `10B <= market_cap < 200B` |
| `mid` | 中盘 | Mid cap | `2B <= market_cap < 10B` |
| `small` | 小盘 | Small cap | `300M <= market_cap < 2B` |
| `micro` | 微盘 | Micro cap | `0 < market_cap < 300M` |
| `unavailable` | 市值不可用 | Market cap unavailable | 缺失或无效 |

显示金额使用紧凑美元格式，保留便于比较的精度：

- 万亿美元：`$4.89T`
- 十亿美元：`$674.9B`
- 百万美元：`$850M`
- 更小金额：使用 `$K` 或完整美元紧凑格式

等级判断始终使用原始数值，不使用格式化文本。

## 后端设计

### 研究目录

扩展 `ResearchUniverseMember`，保存 `market_cap` 与 `market_cap_asof`。成员元数据查询需要选出观察日有效的那一条 membership 记录；如果同一证券存在多段历史成员记录，使用满足有效期条件且 `effective_from` 最大的记录。

### 股票池快照

`merge_research_pool` 将研究成员的市值字段合并到：

- 研究池独有股票；
- 主动池与研究池重叠股票。

主动池中没有研究目录记录的证券返回显式不可用字段。统一的纯函数负责校验市值和计算等级，避免 API、UI 各自维护边界。

### 所选证券

股票详情响应沿用所选股票对应的 universe summary 市值字段，使列表与右侧摘要使用同一来源和同一观察日期，不重新估算。

## 前端设计

### 股票池列表

每张股票卡增加一个市值标签，内容为“等级 · 金额”，例如：

`超大盘 · $674.9B`

标签与板块、动量和 RS 位于同一辅助信息区域。缺失时显示“市值不可用”，使用中性色，不显示 `$0`。

### 所选证券摘要

在收盘价、日涨跌幅、观察日期旁增加“市值”字段，显示同样的等级与金额；市值记录日期通过标题或辅助文本呈现，避免把 2026-07-24 的目录数据误认为 2026-07-27 的实时市值。

### 双语与无障碍

- 中文和英文分别提供等级、不可用状态和字段名称。
- 屏幕阅读器文本包含完整等级、金额及市值日期。
- 颜色仅作辅助，文字本身必须表达等级。

## 错误处理

- 数据库缺少市值列或读取失败时，股票池仍可加载，市值字段降级为不可用。
- 单个证券市值无效不影响其他证券。
- 不用当前价格乘历史股本临时估算，也不把目录筛选阈值当作证券真实市值。

## 测试

- 纯函数边界测试：`200B`、`10B`、`2B`、`300M` 及相邻值。
- 金额格式测试：万亿、十亿、百万、缺失和非法数值。
- 研究目录点时查询测试：同一证券多段 membership 时选观察日有效记录。
- universe API 测试：研究独有、主动重叠、目录外证券和缺失市值。
- 股票详情 API 测试：列表与详情市值及日期一致。
- 前端运行时测试：中英文标签、不可用状态和所选证券摘要。

## 非目标

- 本轮不增加市值范围筛选、排序或直方图。
- 本轮不接入实时市值或稀释后股本计算。
- 本轮不回填 ETF 的资产净值或基金规模；基金规模与公司市值是不同概念。
