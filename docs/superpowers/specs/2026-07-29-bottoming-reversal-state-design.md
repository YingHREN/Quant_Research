# BOTTOM-001 下跌筑底与向上反转状态模型设计

## 目标

把“底部在哪里”从单日猜测改为因果状态诊断。模型只使用观察日及之前的数据，回答当前处于下跌延续、支撑测试、卖压衰竭、向上反转观察、结构确认、突破回踩确认或筑底失败中的哪一阶段。

模型是研究辅助，不输出确定底价，不参与 Ridge 最终方向决策，也不构成买入建议。

## 输入证据

- 价格环境：EMA20 斜率、20 日收益、63 日回撤、是否位于 EMA20 下方。
- 支撑位置：近端支撑区、距支撑距离、支撑强度。
- 卖压衰竭：seller exhaustion、buyer absorption、low-volume higher low。
- 买盘确认：需求确认分、突破接受、突破后跟随。
- 结构反转：向上早期反转、突破前高、突破下降趋势线、更高低点。
- 大盘环境：市场状态机是否支持风险资产。
- 失败证据：放量创新低、跌破冻结支撑、强供应压力。

## 输出状态

1. `downtrend_continuation`：仍处于下跌环境，尚无有效筑底证据。
2. `potential_support`：价格进入或接近可审计的支撑区。
3. `seller_exhaustion_watch`：支撑附近出现卖压衰竭或买方吸收。
4. `early_bullish_reversal_watch`：卖压衰竭后出现需求或早期向上反转证据。
5. `bullish_structure_confirmed`：更高低点与突破类结构证据确认。
6. `breakout_retest_confirmed`：结构突破后回踩守住冻结支撑。
7. `bottom_failed`：观察中的底部被放量创新低或跌破冻结支撑否定。

证据不足或不在下跌筑底语境时输出 `unavailable`，避免把普通上涨阶段误标为底部。

## 记忆与状态迁移

- 正向筑底状态保留最多 10 个交易日，不因单日证据消失立刻归零。
- 更强状态可以升级；较弱单日状态不会立即降级。
- `bottom_failed` 具有即时否决权，并保留 3 个交易日。
- 进入观察时冻结失效位，优先取近端支撑下沿；没有支撑时取近 10 日低点。
- 每次输出状态年龄与是否发生状态迁移，供图表只在关键点画标记。

## UI

- 个股摘要显示当前“筑底状态”和 0–100 分。
- 统一模型面板增加“下跌筑底与向上反转状态模型”，展示五个分项、覆盖率、状态年龄、失效位、支持证据与反证。
- 图表增加独立“筑底状态”图层，只在状态迁移日标记，避免逐日标签遮挡。
- 下方日期详情显示当日状态、分数、状态年龄和失效位。

## 验证

- 单元测试覆盖每个关键状态、记忆、失败否决与输入不变性。
- 前缀不变测试保证追加未来数据不会改写历史输出。
- 历史样本验证需报告覆盖率、不同状态后的 5/10/20 日收益和最大不利波动；在样本外优势未证实前保持研究/建议级权限。
