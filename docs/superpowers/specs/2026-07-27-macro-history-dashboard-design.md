# 宏观历史图表看板设计

## 目标

在“市场与板块”页面增加独立宏观历史图表。用户可以像查看个股历史一样，
沿日期查看宏观综合风险、四个分项、原始宏观序列以及 SPY/QQQ 同期走势，
并在锁定日期后审计当日真实可见的数据、阈值、权重和触发状态。

本功能只展示 `macro_risk_v1` 的历史证据，不修改 Ridge、市场状态分或最终
方向。

## 数据口径

- 每个历史点使用该交易日 UTC 日末以前已经发布的 FRED/ALFRED 版本。
- 交易日期取所选基准 `SPY` 或 `QQQ` 的本地日线日期。
- 综合分、四个分项和十项证据继续由 `research/macro_risk.py` 的冻结规则
  计算，不在前端重算。
- 原始/派生序列支持：
  `DGS2`、`DGS10`、`CURVE_10Y_2Y`、`CPI_YOY`、
  `DCOILWTICO`、`BAMLH0A0HYM2`、`VIXCLS`、`DTWEXBGS`。
- 覆盖率低于 70% 的日期保留在时间轴上，但综合分为空并显示缺失原因。
- 不使用未来修订值补齐旧日期；每个值携带 `observation_date` 和
  `available_at`。

## 后端结构

新增 `MacroHistoryService`，职责仅包括：

1. 从市场库取得基准日期和收盘价；
2. 一次读取截止日期以前可用的宏观观测；
3. 为每个基准交易日构建点时宏观快照；
4. 根据数据库文件版本与市场数据修订号缓存结果。

新增接口：

```text
GET /api/macro-history?range=3y&benchmark=SPY&asof=2026-07-24
```

允许的 `range` 为 `1y`、`3y`、`5y`、`all`，允许的基准为 `SPY`、`QQQ`。
无效参数返回稳定的 400 错误，不接受任意代码或日期范围。

响应包含：

```json
{
  "asof": "2026-07-24",
  "range": "3y",
  "benchmark": "SPY",
  "model_key": "macro_risk_v1",
  "decision_permission": "advisory",
  "series_catalog": [],
  "rows": [
    {
      "time": "2026-07-24",
      "score": 25.0,
      "coverage": 1.0,
      "state": "low",
      "components": {},
      "series": {},
      "evidence": [],
      "benchmark_close": 640.0,
      "unavailable_reason": null
    }
  ]
}
```

`MacroRiskService` 的缓存键必须包含宏观数据库的修改时间和大小。数据库从
缺失/空状态变为有数据后，同一日期不得继续返回旧的 unavailable 结果。

## 前端结构

现有五张宏观摘要卡保持不变，其下增加宏观历史卡：

- 顶部工具栏：`1年 / 3年 / 5年 / 全部`、`SPY / QQQ`、宏观序列选择、
  “解除锁定”按钮。
- 上层图：综合风险分和四个分项，固定 0～100 轴；30、50、70 三条阈值线
  分别表示观察、高风险、严重风险边界。
- 下层图：所选宏观序列与基准同期归一化走势。两者使用独立价格轴，避免
  不同量纲互相压缩。
- 两张图同步可见范围和十字线。单击任一图锁定日期；锁定后鼠标移动、滚动
  到证据区或切换语言都不能改变日期。再次单击或点击“解除锁定”才解锁。
- 明细区展示日期、综合分、覆盖率、四个分项、宏观值及其观察/发布时间，
  以及十项规则的数值、阈值、权重、触发状态和缺失原因。

所有文案提供中文和英文。图表创建失败或数据为空时显示明确状态，不影响
市场页其他区域。

## 性能与缓存

- 默认请求三年；“全部”最多返回本地可用十年数据。
- 后端每个缓存项按宏观数据库版本、市场数据库修订、截止日、区间和基准
  隔离，缓存数量有上限。
- 前端只使用后端分数和证据，不复制评分算法。
- 切换区间或基准时取消旧请求的渲染权，避免慢响应覆盖新选择。

- JavaScript 纯函数测试覆盖行索引、日期选择和锁定状态；资产测试覆盖
  DOM、双语键和脚本语法。
- 浏览器验证覆盖曲线可见、范围/基准/序列切换、日期锁定、证据更新和
  窄屏布局。
- 全量测试通过后才更新中文 TODO 并合入 `main`。
