# 市场压力阶段向下风险专家设计

## 目标与边界

训练一个只回答“从下一交易日开盘进入后，未来路径是否出现显著最大不利
波动”的二分类专家，补足 Ridge 收益率模型和通用方向 Logistic 在半导体
急跌、修正及市场承压阶段的弱点。

本轮是离线研究。专家输出不得修改 Ridge 数值、最终方向或线上否决策略；
只有通过固定样本外门槛后，才能进入后续线上集成设计。

## 标签

标签版本为 `next_open_mae_v1`：

- 观察日收盘后产生信号。
- 下一交易日开盘价是可执行入场价。
- 五日标签：随后第 1～5 个交易日最低价相对入场价不高于 −5%。
- 二十日标签：随后第 1～20 个交易日最低价相对入场价不高于 −10%。
- 标签结束日是窗口最后一个交易日；训练行的结束日必须严格早于测试折首日。
- 路径不完整、入场价非法或任一未来最低价缺失时，标签保持缺失。

这与终点收益方向不同：一只股票可在窗口中先下跌 8%，最后又收涨，因此
风险标签为真而方向标签为上涨。

## 模型与触发范围

采用 `pressure_downside_logistic_v1`：

- 仅使用 `market_regime_v1` 的 `under_pressure`、`correction` 和
  `acute_selloff` 行训练与预测；上涨趋势和震荡阶段输出不适用。
- 输入为冻结的 Ridge v4 点时量价特征、近因衰减动量/量价/相对市场特征，
  加 `regime_is_correction` 和 `regime_is_acute_selloff`。
- 每折只使用训练折中位数填充、训练折裁剪和标准化；禁止全样本预处理。
- 使用类别平衡 Logistic，固定 `random_state=0`、`liblinear` 和 0.5
  判定阈值。模型概率在校准通过前只称“原始模型分数”。

不使用股票代码或当前 SEC 分类独热特征，避免记住单只股票；SEC 分类只用于
样本外分组报告。

## 对比与指标

所有比较必须使用同一测试日期、股票和成熟标签：

- `negative_baseline`：始终不触发风险。
- `ridge_down`：当前 Ridge 的方向为下跌。
- `general_logistic_down`：通用三分类 Logistic 的方向为下跌。
- `pressure_downside_logistic_v1`：本专家分数不低于 0.5。

报告五日和二十日、重叠与按股票/折次抽取的非重叠样本，并按全池、
半导体、软件、其他及三个压力阶段分层。指标包括样本量、事件率、覆盖率、
精确率、召回率、特异度、平衡准确率、ROC AUC、PR AUC、Brier 分数和
相对 Ridge 的可比较折次胜率。

现有 8 项当日风险、12 项记忆风险、板块压力和持续阴跌规则继续使用已有
38 股票统一报告作参考，不伪造为完整 240 股票同池比较。

## 晋级门槛

专家只有同时满足以下条件才可进入后续线上否决集成：

1. 全池五日重叠与非重叠平衡准确率均至少比 `ridge_down` 高 0.01。
2. 全池 PR AUC 高于事件率，且召回不低于 Ridge。
3. 半导体与软件五日重叠/非重叠均不比 Ridge 低 0.005 以上。
4. 急跌、修正、市场承压三个阶段中至少两个阶段赢得多数可比较折。
5. 二十日结果不得出现超过 0.01 的平衡准确率退化。
6. 当前幸存者股票池和最新 SEC 分类快照仍阻止生产晋级。

任何失败原因都写入报告；不得根据实验结果回调标签、阶段或阈值。
