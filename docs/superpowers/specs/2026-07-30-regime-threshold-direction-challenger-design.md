# 市场阶段与经济阈值方向挑战模型设计

## 背景与目标

时间衰减与价格行为层级模型在五日方向分类上小幅优于全局 Logistic，并明显
提高半导体下跌召回，但没有通过晋级门槛。最关键的失败不是单纯准确率不足，
而是“预测下跌”样本的平均实际绝对收益仍为正。这说明模型能够区分类别，却
没有形成可靠的绝对下跌语义。

本实验只研究五个交易日，目标是验证两个冻结假设：

1. 观察日已知的市场阶段能否通过训练折内收缩先验，减少模型在阶段切换后的
   固定牛市截距。
2. 使用严格内层样本外预测选择经济约束下跌阈值，能否使外层测试中
   “预测下跌”组合的平均实际绝对收益稳定小于零，同时不过度牺牲召回。

QQQ 相对方向作为独立诊断目标，用于区分“绝对下跌”和“上涨但跑输大盘”。
它不得替代绝对方向，也不得单独产生线上下跌结论。

## 非目标

- 不修改线上 Ridge、`forecast_decision_policy`、TOPRISK 或任何风险否决。
- 不把相对弱势称为绝对下跌，不在同一指标表中混淆两种标签。
- 不训练板块相对收益头；完整历史点时板块身份不足时，不用当前 SEC 分类
  回填历史。
- 不实现 HMM、神经网络或 Attention，不搜索大量市场阶段定义。
- 不进入 UI，不输出概率，不针对 MU、NBIS、SNDK 等已知日期调参。

## 科学依据与边界

行业成分可以解释个股动量的重要部分，残差动量也能减少随时间变化的共同因子
暴露，因此独立研究市场相对方向有依据。但相对收益为负只表示跑输基准：
股票上涨 2%、QQQ 上涨 8% 时，相对收益为负，绝对收益仍为正。因此相对头只
用于解释和分层，不能修写绝对标签。

市场状态切换模型说明收益与波动分布会随状态变化，但潜在状态模型在短样本中
难以稳定识别，也更难做点时审计。本轮复用已冻结、前缀不变的
`market_regime_v1`，不另行拟合隐状态。

## 数据与标签

- 固定使用上一实验的 240 只研究队列、2018-01-01 起点和同一选择种子。
- 信号在观察日收盘后生成，下一交易日开盘进入，第五个未来交易日收盘退出。
- 绝对收益为股票目标收盘除以下一交易日开盘减一；方向中性区间保持 ±1%。
- QQQ 相对收益为同期股票可执行收益减去同期 QQQ 可执行收益；相对方向中性
  区间固定为 ±1%，只作为独立诊断。
- `market_regime_v1` 的每一行只能使用该观察日及此前 QQQ/SPY 数据。
- 使用五个外层净化扩展测试折。所有训练标签结束日必须严格早于外层测试首日。

## 冻结模型与消融

所有绝对方向候选共享相同外层测试键：

1. `majority_baseline`：训练集多数绝对方向。
2. `ridge_current`：现有 Ridge v4 绝对方向。
3. `logistic_global`：现有类别平衡全局 Logistic。
4. `logistic_regime_prior`：在全局对数概率上增加训练折内市场阶段类别先验
   修正。
5. `logistic_regime_threshold`：在上一模型上增加内层 OOF 经济约束下跌阈值，
   作为主候选。

另建 `logistic_qqq_relative`，使用相同原子特征预测 QQQ 相对方向。它只与
相对多数基线比较，不能与绝对方向模型直接比较准确率。

## 市场阶段收缩先验

每个外层训练折按每个训练观察日当时的 `market_regime_v1` 分组。全局加权
类别比例为 `p_global`，阶段 `r` 的类别后验为：

`p_regime = (count_regime + 1000 * p_global) / (n_regime + 1000)`

阶段修正量为 `log(p_regime) - log(p_global)`。测试行使用观察日已知阶段；
缺失或训练中未见阶段修正为零。先验强度固定为 1000，不根据结果搜索。

## 内层净化 OOF 下跌阈值

阈值选择不得使用外层测试标签。每个外层训练集内部再建立三个净化扩展折，
生成 `logistic_regime_prior` 的内层样本外下跌分数。

冻结候选阈值为 `0.40、0.50、0.60、0.70`。一个阈值只有同时满足以下条件
才可选：

- 内层 OOF 预测下跌覆盖率至少 5%；
- 预测下跌样本至少 500 条；
- 预测下跌组平均实际绝对收益小于 0；
- 下跌 precision 至少比内层 0.50 默认阈值高 2 个百分点。

在满足条件的阈值中，选择平衡准确率最高者；并列时选择更高阈值。没有候选
满足时，该外层折返回显式 `economic_threshold_unavailable`，不得回退到
查看外层结果后选阈值，也不得伪造主候选预测。

主候选的多分类决策保持可解释：

- 下跌分数达到冻结阈值时输出下跌；
- 未达到时，在中性与上涨两个分数中取较大者；
- 阈值仅改变下跌边界，不把相对方向混入绝对方向。

## 评估

绝对方向报告：

- 平衡准确率、macro F1、各方向 precision/recall；
- 预测下跌覆盖率、平均/中位实际收益、胜率和最大不利波动；
- 重叠与非重叠样本；
- 五个外层折和逐折阈值；
- 半导体、软件、其他三组；
- 上涨、震荡、市场承压、修正和急跌；
- 每折训练/测试边界、内层 OOF 数量和不可用原因。

相对方向独立报告同类分类指标，并同时列出每个相对方向桶的平均绝对收益和
平均 QQQ 相对收益，防止语义混淆。

预注册案例为 MU、NBIS、AMD、MRVL、INTC、ADBE、SNDK，在
2026-06-25、2026-06-30、2026-07-01、2026-07-17、2026-07-23 的输出只作
诊断，不参与阈值选择或晋级。

## 冻结历史指标门槛

`logistic_regime_threshold` 只有全部满足才记录 `metric_gate_passed=true`：

1. 五日重叠和非重叠样本中，预测下跌平均实际绝对收益均小于零。
2. 五个可比较外层折中至少四折的预测下跌平均实际收益小于零。
3. 预测下跌 precision 相对 `logistic_global` 至少提高 3 个百分点。
4. 下跌 recall 相对 `logistic_global` 下降不超过 3 个百分点。
5. 平衡准确率相对 `logistic_global` 下降不超过 0.5 个百分点。
6. 重叠与非重叠预测下跌覆盖率均至少 5%。
7. 半导体、软件、其他三组均满足预测下跌平均收益小于零，且平衡准确率下降
   不超过 1 个百分点。
8. 市场承压、修正和急跌合并样本的下跌 precision 与平均收益均优于
   `logistic_global`；任一单独阶段的下跌 recall 不得下降超过 5 个百分点。
9. `logistic_regime_prior` 与主候选至少一个相对上一消融有正增量，不能只有
   已知案例改善。

相对方向头没有线上晋级权，只用于判断共同市场成分与个股弱势分别贡献多少。

即使历史指标全部通过，生产权限仍固定为 `online_authority=none`。完整点时
股票池审计和至少 60 个冻结后真实交易日影子评估完成前，不修改 UI 或决策。

## 产物与测试

新增独立研究模块和运行器，复用现有标签、净化折、市场阶段、研究队列、指标
和原子发布方式。输出 JSON、CSV 和中文 Markdown，保存源码提交、输入内容
指纹、配置、内外折边界、阈值诊断、绝对/相对指标和门槛原因。

测试必须证明：

- 追加未来价格不改变已有市场阶段、训练标签、内层阈值或外层预测；
- 外层测试标签绝不参与阈值选择；
- QQQ 相对标签使用完全相同的进入和退出交易日；
- 相对弱势不会被序列化成绝对下跌；
- 缺失 QQQ、阶段、类别或有效 OOF 样本时显式不可用；
- 所有比较器共享外层测试键，线上 Ridge/API/UI 语义保持不变；
- 严格 JSON 不包含 NaN、绝对路径或凭据。
