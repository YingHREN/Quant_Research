# 统一向下风险走步基准 v2 设计

日期：2026-07-28  
状态：用户已批准按统一走步验证优先实施

## 目标

在不修改线上预测权限和阈值的前提下，用完全相同的点时测试行、未来
路径标签和分组口径，对以下信号进行可复现的扩展窗口走步比较：

- Ridge 原始向下方向；
- 8 项当日向下确认；
- 12 项个股记忆风险；
- TOPRISK 当日确认与持续状态；
- Ridge 加 TOPRISK 的组合策略；
- 已有通用 Logistic 和压力阶段向下专家，作为研究挑战模型。

该实验首先回答三个问题：

1. 哪种方法能更早识别半导体高波动下跌和软件持续阴跌；
2. 改善是否在多数时间折、板块和市场阶段中稳定，而不是来自少数案例；
3. 现有成交量、弱收盘、派发和结构破坏证据是否存在重复计分。

## 采用方案

采用独立离线基准运行器，复用现有点时特征、走步预测器、风险上下文、
动态分组历史和市场阶段状态机。运行器先建立一张不可重复的
`ticker × observation_date × horizon × fold` 测试键表，再把所有模型
输出一对一连接到这张表。只有在同一行上都有可用输出的模型才能做
成对比较；不得把 38 只股票的规则报告与 240 只股票的统计模型报告
直接比较。

不采用以下方案：

- 不把已有报告的汇总指标拼接在一起，因为股票、日期和成熟尾部不同；
- 不在本轮训练神经网络或 Attention 模型，因为当前首要问题是统一验证
  现有模型；
- 不自动搜索最优阈值，因为反复用同一历史调参会扩大过拟合。

## 数据与点时边界

默认实验参数固定为：

- 数据库：`data/research_prices.db`；
- 起始日期：`2018-01-01`；
- 观察截止日：数据库中最后一个所有必要输入均可用的交易日；
- 股票队列：现有扩展研究队列，默认最多 240 只；
- 预测周期：5、10、20 个交易日；
- 时间折：5 个扩展窗口折；
- 入场：观察日收盘后生成信号，下一交易日开盘执行；
- 禁入期：至少等于对应预测周期，训练标签终点必须早于测试折开始日；
- 重叠样本与按周期抽取的非重叠样本分别报告。

历史行业和主题只能从 `group_assignments` 的
`[effective_from, effective_to)` 区间按观察日连接。不得使用当前分类
回填早期未知日期；分类不可用时进入 `unclassified`，不得并入 `other`
掩盖覆盖缺口。

市场阶段复用 `market_regime_v1`，只使用观察日及此前的 QQQ/SPY 数据。
阶段不可用时单独报告 `unavailable`。

## 统一标签

每个观察日使用下一交易日开盘价作为执行价格，分别计算：

- `terminal_return_h`：第 `h` 个交易日收盘相对入场开盘的收益；
- `mae_h`：持有路径中最低价相对入场开盘的最大不利波动；
- `mfe_h`：持有路径中最高价相对入场开盘的最大有利波动；
- `down_event_h`：MAE 达到固定阈值。

风险事件阈值固定为：

- 5 日：MAE 不高于 `-5%`；
- 10 日：MAE 不高于 `-7.5%`；
- 20 日：MAE 不高于 `-10%`。

阈值属于预注册研究口径，不在本轮根据结果修改。数据尾部没有完整未来
路径的行必须剔除，并记录 `immature_row_count`。

## 模型输出与匹配

统一长表至少包含：

- `ticker`、`observation_date`、`horizon`、`fold`；
- `group_key`、`group_source`、`market_regime`；
- `specification`、`predicted_event`、`predicted_score`；
- `terminal_return`、`mae`、`mfe`、`actual_event`；
- `available_at_close`、`executable_at`、`model_version`。

模型定义保持现有生产或研究版本，不重新解释：

- `ridge_down`：Ridge 原始方向为向下；
- `immediate_8`：当日 8 项风险分达到生产阈值；
- `memory_12`：个股记忆风险达到高阈值；
- `toprisk_confirmed`：TOPRISK 原始状态为 confirmed；
- `toprisk_stateful`：TOPRISK 状态为 high、confirmed 或 fading；
- `ridge_plus_toprisk`：现有组合策略输出向下；
- `general_logistic_down`：现有直接方向 Logistic 输出向下；
- `pressure_downside_logistic_v1`：仅在承压、修正或急跌阶段适用的专家。

规则分数不是概率。没有连续分数的二元模型只参与混淆矩阵指标，不制造
ROC AUC、PR AUC 或校准结果。

## 分层与同池比较

固定分层包括：

- 总体；
- 半导体；
- 软件与云服务；
- 其他已分类股票；
- 未分类；
- `uptrend`、`range_bound`、`under_pressure`、`correction`、
  `acute_selloff` 和 `unavailable` 市场阶段；
- 每个走步折；
- 重叠与非重叠样本。

动态分组只决定观察日所属分层，不作为未来标签。每组必须报告当前可比较
模型共同拥有的测试行数以及因数据缺失被排除的行数。

## 指标与晋级门槛

每个模型报告：

- 样本数、信号数、事件率和覆盖率；
- precision、recall、specificity、balanced accuracy、宏平均 F1；
- 平均终点收益、平均 MAE、平均 MFE；
- 首次信号到首次达到风险阈值的提前交易日数；
- 误报率以及误报后的平均机会成本；
- 相对 Ridge 和始终不报警基线的成对差值；
- 可比较折数和赢得折数。

本轮只允许给出研究结论。模型必须同时满足以下条件才可进入下一轮线上
晋级评审：

1. 5 日和 20 日非重叠样本的下跌召回率均优于 Ridge；
2. specificity 不得比 Ridge 低超过 5 个百分点；
3. balanced accuracy 在至少 3/5 个可比较时间折中优于 Ridge；
4. 半导体和软件分层都至少有 3 个可比较折，且各自多数折不退化；
5. 最新留出折不退化；
6. 结果不能只由单一市场阶段贡献。

即使通过以上门槛，也只获得“可进入生产影子评估”的资格，不自动获得
线上否决权。

## 因子消融

对 8 项当日风险和 TOPRISK 的原子证据按独立信息组消融：

1. 成交量参与：异常量、成交量扩张；
2. 收盘与卖压：弱收盘、有符号成交压力；
3. 趋势结构：跌破 EMA20、突破失败、趋势线或支撑破坏；
4. 相对环境：跑输点时板块、板块压力、大盘阶段；
5. 高位背景：前置涨幅、均线延伸、末端加速。

每次只移除一个组，重新生成规则输出并在相同测试键上比较。若移除某组
后 precision、recall 和 balanced accuracy 均未下降，则该组标记为
“未证明增量价值”；本轮不直接删除生产因子。

同时生成原子证据相关矩阵和同日共同触发率，识别派发、异常量、放量和
弱收盘的重复贡献。

## 组件边界

新增独立模块：

- `research/unified_downside_benchmark.py`：统一标签、同池连接、指标、
  成对比较和消融；
- `research/run_unified_downside_benchmark.py`：冻结参数、加载数据、
  调用现有模型并输出报告；
- `tests/test_unified_downside_benchmark.py`：纯函数和因果边界；
- `tests/test_run_unified_downside_benchmark.py`：运行器、manifest 与
  确定性输出；
- `reports/unified-downside-benchmark-v2.{json,csv,md}`：真实研究结果。

现有 `evaluate_toprisk_comparison.py` 和
`run_pressure_downside_study.py` 保持兼容，v2 通过适配器复用它们，
不复制模型公式。

## 错误处理

- 某模型缺失时标记为 `unavailable`，不得默认视为未报警；
- 点时分类缺失时进入 `unclassified`；
- 市场阶段缺失时进入 `unavailable`；
- 某分层只有一个实际类别或样本不足时不计算胜负；
- 重复测试键、训练标签穿越测试起点或一对一连接失败时立即终止；
- 单个报告文件写入失败不得留下部分成功的正式 manifest；
- 真实实验不得修改行情数据库、分析缓存或线上模型配置。

## 测试与验收

- 先写失败测试，再写实现；
- 验证次日开盘标签、成熟尾部剔除、禁入期和前缀不变性；
- 验证动态分组按观察日连接，离组和重入区间不桥接；
- 验证所有模型使用完全相同的测试键；
- 验证二元规则不伪造概率指标；
- 验证非重叠抽样、市场阶段分层、稀疏折排除和成对折胜率；
- 验证消融只移除指定证据组；
- 固定输入重复运行必须生成语义相同的 JSON、CSV 和 Markdown；
- 运行相关测试及完整 Python 测试；
- 在真实研究库上生成报告并将结论写回中文全局 TODO。

## 非目标

- 不改变网页或线上 `forecast_decision_policy`；
- 不自动调参或写回生产阈值；
- 不训练 Attention、深度学习或新的神经网络；
- 不接入盘中数据、基本面或 13F；
- 不声称规则分数是概率；
- 不因 MU、NBIS、MRVL、SNDK 或 ADBE 个别案例调整固定门槛。
